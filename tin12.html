✔ Bảng chuẩn hóa kiến thức Phiếu học tập số 1:

1. CSS trong (Internal CSS)

Vị trí: Viết trong cặp thẻ <style>...</style> đặt tại phần <head> của tệp HTML.

Phạm vi: Áp dụng cho toàn bộ 01 trang web (tệp HTML) hiện thời.

Ưu/Nhược & ATM: Tiện cho trang đơn; tách biệt mã giúp dễ kiểm soát, phát hiện mã lạ ẩn nội dung.

2. CSS ngoài (External CSS)

Vị trí: Lưu trong tệp .css riêng biệt, kết nối bằng <link> hoặc @import.

Phạm vi: Áp dụng đồng bộ cho nhiều trang web hoặc cả một website.

Ưu/Nhược & ATM: Tối ưu băng thông, dễ bảo trì; tuyệt đối không nhúng link CSS từ tên miền lạ để tránh CSS Injection.

3. CSS nội tuyến (Inline CSS)

Vị trí: Viết trực tiếp trong thuộc tính style="..." của thẻ mở HTML.

Phạm vi: Chỉ áp dụng cho duy nhất 01 phần tử HTML cụ thể đó.

Ưu/Nhược & ATM: Sửa nhanh cục bộ nhưng lặp mã, khó bảo trì trên quy mô lớn.

1. Hiểu khái niệm, cấu trúc và vai trò CSS
 Chưa phân biệt được cú pháp CSS với HTML; chưa nêu được vai trò của CSS. Nêu đúng cấu trúc bộ chọn – vùng mô tả và giải thích được vai trò tách biệt nội dung – định dạng. Phân tích sâu sắc lợi ích tối ưu băng thông, tốc độ tải trang và khả năng bảo trì của CSS.
3.1.NC1a 5.2.NC1a
2. Thiết lập và lựa chọn cách dùng CSS
 Chưa viết được mẫu CSS hoặc kết nối sai tệp CSS ngoài với trang HTML. Thiết lập đúng CSS trong, ngoài, nội tuyến trong ví dụ cơ bản; trang web hiển thị đúng yêu cầu. Lựa chọn linh hoạt cách thiết lập CSS tối ưu; tổ chức thư mục dự án web khoa học, sạch mã.
1.1.NC1b 6.1.NC1a
3. Khai thác học liệu số & Kiểm chứng AI
 Chỉ sao chép thụ động mã nguồn từ mạng/AI mà không hiểu thuộc tính. Tìm kiếm được thông tin từ nguồn tin cậy và giải thích được ý nghĩa các thuộc tính CSS sử dụng. Chủ động đối chiếu tài liệu chuẩn (W3C/MDN), phát hiện và sửa được lỗi trong mã gợi ý.
4.1.NC1c 4.2.NC1a
4. Thực hành An toàn trên không gian mạng
 Chèn liên kết CSS từ nguồn lạ không kiểm chứng hoặc để lộ thông tin cá nhân trên máy thực hành. Sử dụng tệp CSS nội bộ an toàn; tuân thủ quy tắc bảo mật tài khoản khi làm bài trực tuyến. Nhận diện được rủi ro giả mạo giao diện/CSS Injection từ nguồn ngoài và chủ động phòng tránh.
